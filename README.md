## What I've shipped

**[HeadacheWise](https://apps.apple.com/us/app/headachewise/id6670711602)** — Migraine and
headache tracking, live on iOS. 160+ users, 2,000+ logged episodes. Congressional App
Challenge winner. Built and maintained solo.

**[Nárm](https://apps.apple.com/us/app/narm-clothing-fabric-scanner/id6769256623)** — AI
fabric-safety analysis: scan a garment, understand what you're actually wearing. Technical
co-founder and sole engineer.

**PaCo** — Research platform at Northwestern's Institute for AI in Medicine. I built the LLM
analysis layers, a multi-provider failover system across Gemini, OpenAI, and Groq, and the
QUILAM instrument mapping. Code lives in the lab's repository.
